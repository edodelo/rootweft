# Rootweft v0.1.0-alpha Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a public, installable, offline-first structural repository knowledge-graph tool with an optional bounded Jev adjudication overlay, read-only MCP access, a portable Agent Skill, and a verified `v0.1.0-alpha` GitHub release.

**Architecture:** A deterministic structural pipeline scans and parses supported source files into a versioned JSON graph. A capability-limited decision adapter may send only bounded candidates to an explicitly selected Jev provider and stores results in a separate overlay. CLI, MCP, skill installer, and viewer consume public graph/query services and cannot mutate repositories.

**Tech Stack:** Python 3.11–3.13, standard-library AST/dataclasses/argparse, `tree-sitter` with official JavaScript and TypeScript grammar wheels, `httpx`, official MCP Python SDK v2, pytest, Ruff, mypy, build, pip-audit.

**Spec:** `docs/superpowers/specs/2026-09-20-rootweft-v0.1-design.md`

## Global Constraints

- Product/package/executable name is `rootweft`; repository name is `rootweft`.
- Python package version is PEP 440 `0.1.0a1`; the human-facing Git tag and release name are `v0.1.0-alpha`.
- License is Apache-2.0; no Graphify source, prompt, test, documentation, asset, UI, or branding may be copied.
- Python support is exactly 3.11–3.13 for this release.
- Network access is disabled by default and requires `--enable-remote`; OpenRouter is never an automatic fallback.
- The structural graph is immutable and deterministic; Jev decisions live only in the adjudication overlay.
- MCP loads one explicit graph and is strictly read-only with no network or arbitrary path arguments.
- All repository-derived strings are untrusted; viewer and protocol outputs must neutralize active content.
- Machine stdout is valid JSON/JSONL or MCP frames only; diagnostics use stderr.
- Paths persisted in graph artifacts are relative POSIX paths, never absolute paths.
- Production code is added test-first. Each task ends with its focused test suite and a commit.
